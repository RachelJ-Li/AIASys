# 标准验证方法

## 通用验证

- 数据和运行可追溯
- 约束和边界检查
- 基线或候选模型对比
- 稳定性或敏感性分析
- 适用范围和局限

## 优化模型

- 可行率
- 目标函数值
- 最优性差距
- 收敛性
- 运行时间
- 资源消耗

## 回归与预测

- MAE
- RMSE
- MAPE
- R²
- 残差分析
- 交叉验证
- 置信区间

## 分类模型

- Precision
- Recall
- F1
- ROC-AUC
- PR-AUC
- 混淆矩阵
- 概率校准

## 时间序列

- 滚动验证
- 预测误差
- 残差自相关
- 简单预测基线
- 不同时间窗口稳定性

## 聚类与评价模型

- 轮廓系数
- 聚类稳定性
- 权重敏感性
- 排序一致性
- 替代方法对比

## 微分方程与仿真

- 数值收敛
- 步长敏感性
- 守恒关系
- 极端情形
- 蒙特卡洛误差
- 解析解或高精度解对比

## 生物模型

- 统计显著性
- 多重检验校正
- 独立数据验证
- 批次效应
- 生物学合理性
- 已知通路或标志物一致性

## 通用回退

问题类型未覆盖时，至少执行：

- 约束或合理性检查
- 基线对比
- 稳定性分析
- 结果可复现性检查

只规定验证维度，不硬编码统一阈值。阈值必须来自赛题、文献、数据分析或模型合同。
