# 文献检索参考

适用于文献与资料检索阶段。

## 联网策略

### 读取赛题规则

每次联网前，先读取：

- `statement/constraints.md`
- `modeling/index.json` 中的 `research_policy`

### 默认策略

- 默认允许联网检索论文和公开资料
- 赛题明确禁止联网时，更新 `research_policy.network_allowed = false`

## 检索原则

1. 优先使用原始论文、官方文档、标准和权威机构数据
2. 不得仅根据模型记忆生成论文标题、DOI 或链接
3. 重要参考文献应尽量核验 DOI、出版机构页面或原始来源
4. 每条参考资料至少登记：标题、作者或机构、年份、来源链接、访问日期、用途

## 来源可信度排序

1. 同行评议期刊论文
2. 会议论文（知名会议）
3. 技术报告（政府、国际组织）
4. 预印本（需注明）
5. 博客/教程（需谨慎使用）

## 禁止伪造引用

- 不得伪造文献标题、作者、年份或链接
- 无法核验的来源不得进入最终参考文献
- 正文中未使用的资料不必进入参考文献

## 参考文献格式

Markdown 参考文献（`research/references.md`）：

```markdown
## 参考文献

1. 作者. 标题[J]. 期刊, 年份, 卷(期): 页码. DOI
2. 作者. 标题[C]//会议名称. 年份: 页码.
```

JSON 参考文献（`research/references.json`）：

```json
[
  {
    "id": "ref-001",
    "title": "",
    "authors": [],
    "year": null,
    "source": "",
    "url": "",
    "doi": "",
    "accessed_date": "",
    "status": "verified",
    "used_in": []
  }
]
```

`status` 可选值：
- `verified`：已核验来源
- `pending`：待核验
- `unverifiable`：无法核验，不进入最终文献

## 进入下一阶段的条件

- 每个核心子问题有方法依据或明确的自主推导路径
- 参考文献来源可追溯
- 联网行为符合赛题规则

## 暂停条件

- 赛题规则对联网或外部资料的规定不明确且影响合规性
- 完成任务必须访问用户专属、付费或受限资料
