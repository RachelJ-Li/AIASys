# 问题分析参考

适用于材料接收和问题理解两个阶段。

## 题目解析

### 输入检查清单

读取 `statement/` 目录下的文件：

- `statement/problem.md`：赛题原文或翻译
- `statement/requirements.md`：提交要求、格式规范
- `statement/constraints.md`：假设条件、赛题约束、工具限制

> 完整流程契约见 `workflow.md`。

### 问题重述模板

```markdown

### 任务目标

[一句话概括要解决的核心问题]

### 已知条件

- [条件 1]
- [条件 2]

### 求解目标

- [目标 1]
- [目标 2]

### 约束条件

- [约束 1]
- [约束 2]
```

### 问题类型识别

根据题目特征判断问题类型：

| 类型 | 特征 | 常见方法 |
|------|------|----------|
| 优化问题 | 最小/最大化目标函数 | 线性规划、非线性规划、启发式 |
| 预测问题 | 基于历史数据预测未来 | 回归、时间序列、机器学习 |
| 评价问题 | 多指标综合评估 | 层次分析、熵权法、TOPSIS |
| 分类问题 | 划分类别或等级 | 判别分析、聚类、分类器 |
| 微分方程 | 动态系统建模 | 解析解、数值解、仿真 |
| 图论问题 | 网络结构优化 | 最短路径、最小生成树、流 |

## 数据理解

### 数据质量检查

检查 `data/raw/` 目录：

1. **字段检查**：列名、数据类型、单位
2. **缺失值**：统计每列缺失比例
3. **异常值**：统计描述、分布可视化
4. **一致性**：时间序列顺序、ID 唯一性

## 子问题拆解

### 拆解原则

1. 每个子问题有明确的输入、输出和验收条件
2. 子问题之间依赖关系清晰，无循环
3. 题目要求完全覆盖，无遗漏

### 子问题结构

```json
{
  "subproblems": [
    {
      "id": "P1",
      "title": "子问题标题",
      "requirement_refs": ["requirements.md#L10-L15"],
      "input_paths": ["data/raw/data.csv"],
      "expected_outputs": ["results/summary_P1.md"],
      "dependencies": [],
      "status": "pending"
    }
  ]
}
```

## 进入下一阶段的条件

- 问题分析文件已创建
- 数据画像已完成
- 子问题列表已登记到 `modeling/index.json`

## 暂停条件

- 题目存在影响任务目标的关键歧义
- 必需字段缺失且无法推导或替代
- 数据错误无法自动修复，需要确认版本
